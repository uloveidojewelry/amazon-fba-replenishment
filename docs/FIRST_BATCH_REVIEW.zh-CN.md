# 第一批真实 SKU 映射审核说明

本批从 `sku_batch_review.xlsx` 的“精确匹配优先”工作表提取 852 个 SKU。
336 个审核决定包括 307 个可按系列审核的明确集合，以及 29 个格式异常单体组。
精确匹配是审核依据，仍需人工确认，不代表已批准。

## 在 Excel 中操作

1. 打开 `first_batch_sku_mapping_review.xlsx`，先看“审核决定”。有样本正销量
   证据的组优先，其次有 FBA 库存或在途数量的组；异常另列“异常待核”。
2. 对每一组，复制或筛选 `group_id`，在“SKU完整明细”中查看该组全部 SKU、
   ASIN、候选系列、上传表精确匹配来源、六类库存数量、样本销量证据及异常。
   `sku_count`/`group_member_count` 是该次明确成员数量，不包含未来同前缀 SKU。
3. 在黄色可填写单元格作决定：
   - `APPROVE`：已核实这组全部明确成员属于同一系列。填写 `approved_family`
     （与该组候选一致）、`reviewer`（审核人）和 `reason`（确认依据）。
   - `REJECT`：否定本组候选映射。填写审核人与拒绝理由。
   - `NEEDS_REVIEW`：证据不足或暂未处理。所有 336 个决定默认此值。
4. 29 个格式异常组可拒绝或继续待核，不能在当前文件中直接批准。单独核实
   SKU 空格、尺寸格式及系列归属后，重新生成明确单体审核集合，再次校验。
5. `snapshot_id`、`group_id`、`manifest_id`、`member_digest`、SKU、ASIN、候选
   系列和成员数量是固定身份字段，不修改、不增删成员。需要纠正候选或成员
   时重新生成集合。Excel 锁定防止误操作，实际安全仍由模拟校验检查。

审核决定可以按组填写，无需逐条批准该组所有 SKU；确认前必须看完整成员表。
选择 `APPROVE` 只是提交人工意见，不会从 Excel 自动导入或触发补货。

## 标记停补

在“停补标记”选择已核实的触发 SKU，填写：

- `stop=TRUE`：申请停补。
- `reason`：停补原因。
- `effective_date`：`YYYY-MM-DD`，按美国站业务日期（America/Los_Angeles）。
- `review_status=APPROVE`、`reviewer`：明确的停补决定与审核人。

停补必须基于已确认的正式映射。若同一文件中同时提出映射批准和停补，模拟
会预测批准后的联动范围；实际操作仍需先经用户确认正式映射，再处理确认的
停补记录。同站点某个子体停补会使已确认属于同系列的全部子体建议为 0，
包括该审核组之外的已确认子体。请查看模拟报告里的范围外影响提示。

空白表示尚未决定；FALSE 不会恢复补货。恢复始终需要单独人工确认，不能
通过本次审核表解除已有停补。未知候选系列不能被当成正式停补范围。

## 数据应如何理解

本批有 611 个 SKU 的可售/预留/不可售库存至少一项大于零；另有 58 个仅有
入仓数量，因此含在途的正数量 SKU 共 669 个。库存为零不等于下架，Listing
状态仍为 UNKNOWN。

10 个 SKU 有小批量样本正销量证据，另外 842 个是 UNKNOWN，不能填零。
样本观察量或每组已知观察量之和不是完整 7、30、60、90 天销量，也不包含
未知成员的销量。29 个异常为格式提示，当前系列映射冲突为 0。

数量及采集时间来自原审核表的保存快照。本轮未重新请求 Amazon；如后续
数据库状态变化，需在导入前再次模拟。

## 提交前模拟校验

保存你填写后的副本，保留所有固定身份及完整成员，然后执行：

```bash
fba-plan --db output/sku-review/review.db simulate-first-review \
  output/first-batch-review/first_batch_sku_mapping_review.xlsx \
  --source output/batch-review/sku_batch_review.xlsx \
  --output output/first-batch-review/edited_review_simulation.json
```

保留原始 `sku_batch_review.xlsx` 作为独立来源，不要用已编辑的第一批表替代。
该命令以只读数据库连接运行，检查：整组遗漏或替换、组成员增删/重复、ASIN、校验值、冻结
原始状态变化、映射冲突、人工正式映射保护、已存在停补，以及可能联动的
范围外子体。不会通过“先实际批准再回滚”模拟，也不创建或修改审核记录。

初始校验为：336 组结构一致，852 个成员无变更、系列冲突 0；307 组具备
审核条件，29 组格式异常仍需解决。全部意见为 NEEDS_REVIEW，不允许导入。
即使之后模拟通过，结果中的 `import_permitted` 仍为 false；模拟不是授权。

审核完成后，将审核副本和模拟结果交回，并明确确认要正式导入的批准/拒绝
集合及停补范围。收到用户明确确认后，才进行正式配置导入。当前不提供自动
导入动作，原有正式映射、停补状态和补货建议保持不变。

本阶段不进行完整 90 天销量采集、不部署调度、不创建 FBA 货件，不修改
Listing、库存或价格。所有补货仍用于人工审核。
